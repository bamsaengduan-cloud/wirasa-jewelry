WIRASA — Editable Website Package

ไฟล์หลัก
1) index.html — เนื้อหาและโครงสร้างเว็บ
2) styles.css — สี ฟอนต์ ระยะห่าง และรูปแบบทั้งหมด

วิธีแก้ง่าย ๆ
- เปิด index.html ด้วย Chrome เพื่อดูหน้าเว็บ
- เปิด index.html ด้วยโปรแกรมแก้ข้อความ เช่น VS Code / Notepad++
- ค้นหาคำว่า PLACE IMAGE แล้วเปลี่ยนเป็นรูปจริงภายหลัง
- ข้อมูลที่ยังไม่มี เช่น ราคา วัสดุ Social Media และ QR Code ตั้งใจเว้นไว้เป็น placeholder

การเอาไปใช้ออนไลน์
- เหมาะสำหรับอัปโหลดขึ้นบริการ Static Hosting เช่น Netlify, GitHub Pages หรือ Cloudflare Pages
- หากใช้ Wix/Webflow ให้ใช้ไฟล์นี้เป็นต้นแบบ แล้วนำข้อความ/รูป/โครงสร้างไปวางในตัวแก้ไขของแพลตฟอร์ม

ธีม
- Ivory / Champagne Gold / Deep Brown
- Minimal Luxury / Editorial Jewelry

หมายเหตุ
- เว็บเป็น responsive ใช้ได้ทั้งคอมพิวเตอร์และมือถือ
- สามารถเปลี่ยนชื่อแบรนด์ ข้อความ สี และรูปได้ทั้งหมด
